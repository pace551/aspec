# CLAUDE.md — rpn

Reverse-polish-notation calculator. Worked example for STK-RUST: `thiserror` typed
errors in the lib, `anyhow` chains in the bin, mechanical unwrap/expect ban via the
Cargo `[lints]` table, lcov coverage feeding the ratchet.

Governed project — tier and applicable standards in `GOVERNANCE.md`; run
`/verify-compliance` before calling any work done (Constitution C2).

## Structure

```
examples/rust/
├── Cargo.toml         # [lints.clippy] unwrap_used/expect_used = deny (STK-RUST-03)
├── src/lib.rs         # eval() + RpnError enum; #[cfg(test)] mod tests (8 tests)
└── src/main.rs        # thin anyhow::Result main over the lib (STK-RUST-07)
```

## Commands

All commands runnable verbatim from repo root:

```bash
scripts/lint.sh                  # cargo fmt --check + clippy -D warnings (same gate as hook and CI)
scripts/test.sh                  # cargo-llvm-cov → lcov.info (same gate as hook and CI)
cargo run -- 3 4 + 2 '*'         # run the thing
```

One-time tool installs: `cargo install cargo-llvm-cov cargo-audit`.

## Gotchas

- The one "unreachable" branch in `eval()` returns a typed error with an
  `// INVARIANT:` comment instead of panicking — that is the STK-RUST-03 pattern for
  provable invariants.
- `Cargo.lock` must be committed once generated by the first `cargo build`
  (STK-RUST-06). Not yet generated: no Rust toolchain was available on the authoring
  machine — run `cargo build` and commit it.
